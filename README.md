# -CASO-PRACTICO-FASTPASS-UNI

Historias de Usuario
HU1
Como estudiante de la universidad, quiero visualizar el menú disponible en los diferentes puntos de venta, para conocer las opciones de comida antes de realizar mi pedido y elegir la que más me convenga.


HU2
Como estudiante, quiero consultar el menú del día y su disponibilidad, para evitar pedir un alimento que ya esté agotado cuando llegue al punto de venta.

HU3
Como estudiante, quiero realizar mi pedido de comida desde la aplicación antes de llegar a la cafetería,
para ahorrar tiempo y evitar hacer largas filas durante la hora de almuerzo.


HU4
Como estudiante, quiero pagar mi pedido desde la aplicación móvil, para no tener que hacer fila en la caja y solo pasar a recoger mi comida cuando esté lista.



HU5
Como estudiante, quiero recibir una notificación cuando mi pedido esté listo, para dirigirme al punto de venta en el momento adecuado y recoger mi comida sin esperar.

REQUISITOS FUNCIONALES DE FASTPASS UNI
RF1 – Visualización del menú
El sistema debe permitir a los estudiantes visualizar el menú disponible de todos los puntos de venta de la universidad, mostrando información como el nombre del producto, descripción, precio y disponibilidad, con el fin de que puedan conocer las opciones antes de realizar un pedido.

RF2 – Consulta del menú del día
El sistema debe permitir a los estudiantes consultar el menú del día ofrecido por la cafetería, indicando si el producto está disponible o agotado, para evitar que los estudiantes realicen pedidos de alimentos que ya no se encuentran disponibles.

RF3 – Realización de pedidos anticipados
El sistema debe permitir a los estudiantes seleccionar productos del menú y realizar pedidos anticipados desde la aplicación móvil, indicando la cantidad de productos deseados antes de acudir al punto de venta.

https://lucid.app/lucidchart/4148bb14-57d6-4186-a412-1add00d1c024/edit?viewport_loc=-1502%2C61%2C2753%2C1442%2C0_0&invitationId=inv_415d465f-05ba-430e-b7b3-cf7e7bb98e6d

RF4 – Pago del pedido desde la aplicación
El sistema debe permitir a los estudiantes realizar el pago del pedido directamente desde la aplicación mediante los métodos de pago disponibles, confirmando el pedido una vez que el pago haya sido procesado correctamente.

RF5 – Notificación de pedido listo
El sistema debe enviar una notificación al estudiante cuando el pedido haya sido preparado y esté listo para ser recogido en el punto de venta correspondiente.
