Caso Práctico: “FastPass Uni: Pide desde tu celular,Paga y Recoge tu Alimento”
Descripción del Proyecto

FastPass Uni es una aplicación móvil diseñada para mejorar la experiencia de los estudiantes durante la hora de almuerzo en la universidad. Actualmente, los puntos de venta y la cafetería presentan largas filas y tiempos de espera elevados, lo que provoca que muchos estudiantes pierdan gran parte de su tiempo de descanso o incluso lleguen tarde a sus clases.

La aplicación permitirá a los estudiantes consultar el menú disponible, realizar pedidos anticipados y pagar directamente desde su dispositivo móvil. De esta manera, los estudiantes podrán hacer su pedido desde cualquier lugar del campus y solo acudir al punto de venta cuando su comida esté lista para ser recogida.

Con esta solución se busca reducir las filas, mejorar la organización en los puntos de venta y optimizar el tiempo de los estudiantes, permitiéndoles acceder a su almuerzo de forma más rápida y eficiente.

Historia de Usuario 1: Consultar el menú disponible

Como estudiante de la universidad,
quiero ver el menú disponible en los diferentes puntos de venta dentro de la app,
para conocer las opciones de comida antes de hacer mi pedido y elegir la que prefiera.

Requerimientos funcionales:

El sistema debe permitir visualizar los productos disponibles en cada punto de venta de la universidad.

El sistema debe mostrar información básica de cada producto, como nombre, precio, descripción y disponibilidad.

El sistema debe actualizar la información del menú cuando un producto ya no esté disponible.

Historia de Usuario 2: Consultar el menú del día

Como estudiante,
quiero ver el menú del día y verificar si aún está disponible,
para evitar seleccionar un alimento que ya se haya agotado.

Requerimientos funcionales:

El sistema debe mostrar el menú del día ofrecido por la cafetería.

El sistema debe indicar si el producto está disponible o agotado.

El sistema debe actualizar automáticamente la disponibilidad del menú cuando se terminen los productos.

Historia de Usuario 3: Realizar pedidos desde la aplicación

Como estudiante,
quiero hacer mi pedido de comida desde la aplicación antes de llegar a la cafetería,
para reducir el tiempo de espera y evitar las filas durante la hora de almuerzo.

Requerimientos funcionales:

El sistema debe permitir al usuario seleccionar los productos que desea pedir.

El sistema debe permitir añadir varios productos dentro de un mismo pedido.

El sistema debe permitir confirmar el pedido antes de enviarlo al punto de venta.

Historia de Usuario 4: Pagar el pedido desde el celular

Como estudiante,
quiero realizar el pago de mi pedido directamente desde la aplicación,
para no tener que hacer fila en la caja y recoger mi comida de forma más rápida.

Requerimientos funcionales:

El sistema debe permitir efectuar el pago del pedido mediante la aplicación móvil.

El sistema debe informar al usuario si el pago se realizó correctamente o si fue rechazado.

El sistema debe generar un comprobante digital del pago realizado.

Historia de Usuario 5: Recibir aviso cuando el pedido esté listo

Como estudiante,
quiero recibir una notificación cuando mi pedido esté preparado,
para acercarme al punto de venta en el momento adecuado y recogerlo sin esperar.

Requerimientos funcionales:

El sistema debe enviar una notificación al estudiante cuando el pedido esté listo.

El sistema debe permitir visualizar el estado actual del pedido (en preparación, listo o entregado).

El sistema debe enviar las notificaciones directamente al dispositivo móvil del usuario.
